# @polygonplus/web

Dashboard de PolygonPlus (Next.js App Router) → desplegado en **Vercel**.

```bash
pnpm --filter @polygonplus/web dev     # http://localhost:3000
```

Variables (ver `.env.example` en la raíz): `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`.

Hoy es un esqueleto (Fase 0). La Fase 1 monta aquí el tablero operativo y el dashboard por marca.
