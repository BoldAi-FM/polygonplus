# Procesos (SOPs) — Núcleo de Conocimiento

Aquí vive el conocimiento operativo de Polygon convertido en documentos: **la cura contra la dependencia de personas clave.** Cada proceso que hoy vive en la cabeza de alguien se documenta como un SOP.

## Formato de un SOP

Cada archivo describe un proceso con: disparador, pasos, responsables, entradas/salidas, y qué agente lo asiste o automatiza.

## Por documentar (backlog inicial)

- Ciclo mensual de una cuenta en iguala (de la planeación al reporte). *Nota: cada cuenta es distinta; se documentan una por una.*
- Flujo de una petición del cliente (recepción → priorización → aprobación → ejecución → entrega).
- Handoff dirección → PM → cuentas.
- Proceso de reporte al cliente.
- Onboarding de un cliente nuevo.
